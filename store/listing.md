# Play Store listing copy

Paste as-is. The wording is deliberately free of the things that trigger metadata
rejections: no "best", "#1", "top", "free", no prices, no emoji, no ALL CAPS in the
name, no keyword lists, no third-party brand names.

**App name** (25/30)

```
Gradiente: Gradient Maker
```

**Short description** (75/80)

```
Create beautiful color gradients and export them as wallpapers or CSS code.
```

**Full description** (under 4000)

```
Gradiente is a simple, fast gradient maker for your phone.

Pick a few colors, adjust the angle, and get a smooth gradient in seconds. Use it as a wallpaper, share it with friends, or copy the code straight into your website or app.

CREATE
- Linear and radial gradients
- Up to 5 color stops with precise positions
- Color wheel and hex input
- Randomize for instant inspiration
- Undo and redo

EXPLORE

EXPORT

FOR DEVELOPERS AND DESIGNERS

PRIVATE BY DESIGN
```

## Store settings

| Field | Value |
|---|---|
| Category | Personalization (alternative: Art & Design) |
| Tags | Wallpapers, Design, Color |
| Contact email | a public support address — must match `SUPPORT_EMAIL` in `src/constants/links.ts` |
| Website | the privacy policy URL works |

## Graphic assets

| Asset | File | Status |
|---|---|---|
| App icon 512x512 | `store/icon-512.png` | generated, matches the launcher icon |
| Feature graphic 1024x500 | `store/feature-graphic.png` | generated, 24-bit PNG, no alpha |
| Phone screenshots | `store/screenshots/` | **you must capture these on a real device** |

Provide at least 4 phone screenshots (9:16, 1080x1920 or larger) to stay eligible
for featuring. They must show the real app — mock-ups get rejected. Suggested set:
Create screen with a bold gradient, the preset grid, the export sheet, the code sheet.
